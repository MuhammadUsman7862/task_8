Lesson 1: Your First Web Page

By Muhammad Usman | 15 min read

Every web page starts with HTML. It describes what is on the page, and CSS describes how it looks. In this lesson you build a simple profile page and style it.

What you will do

  1. Create an index.html file with a header, main and footer.
  2. Add headings, paragraphs and a list of your skills.
  3. Link a style.css file and change the colours and fonts.
  4. Open the page in the browser and inspect it with DevTools.

Tip

Save often and refresh the browser after every small change.
